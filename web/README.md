# FieldNotes Web

React 19 + TypeScript 巡检管理工作台。只读取和处理真实问题，现场标注与创建在 Unity 手机端完成。启动时不会写入演示数据。

## 本地运行

需要 Node.js 22.12 或更新版本，以及运行中的 Go 服务。

```sh
cd web
npm ci
npm run dev
```

打开 `http://localhost:5173`。Vite 监听 `0.0.0.0:5173`，端口被占用时明确报错。开发代理将 `/api` 请求转发到 `http://127.0.0.1:8080`。如后端位于其他地址，复制 `.env.example` 为 `.env` 并修改 `API_PROXY_TARGET`；修改后重启开发服务器。浏览器中的请求始终使用同源 `/api`。

```sh
npm test -- --run
npm run build
```

构建产物位于 `web/dist`，生产托管需让 `/api` 路由到 Go 后端。`npm run preview` 仅预览静态产物，不提供开发 API 代理。

## 操作

列表显示标题、优先级、状态和上报时间，可按状态、优先级及标题/描述/ID 筛选。选择问题标题后，详情面板显示描述、AR 会话坐标、创建和更新时间。修改状态后选择“保存状态”。保存期间禁止重复操作；失败时保留服务端原状态并显示重试说明。

加载与保存请求在 10 秒后超时。服务不可用、HTTP 错误和非预期响应均显示错误提示。刷新失败时保留已加载记录并标明它们来自上次加载；刷新成功时按 ID 保留选中项，记录不存在时关闭详情。状态统计基于全部已加载问题，筛选不会改写统计值。

界面使用系统字体，无远程字体或图片。桌面列表与侧栏并列，窄屏详情置于列表之后；支持键盘选择、聚焦详情、关闭后恢复焦点、可访问表单标签与 reduced-motion。

## 测试范围

Vitest + Testing Library 通过 mock fetch 验证加载、空集合、连接失败与重试、筛选、详情、状态更新成功/失败、重复提交禁用、刷新选择保留、异常数据及超时。真实 Go 集成与浏览器尺寸检查属于项目集成验收；这里的 mock 记录只存在于测试文件。
