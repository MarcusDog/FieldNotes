# 演示录像

当前已提供手机与电脑短视频，时长和覆盖检查见 [交付检查](DELIVERY_CHECK.md)。以下保留题目要求对应的完整演示操作顺序，供复核使用。

必须录制真实操作，不能把 API 测试、Unity Editor 模拟画面或截图动画称为真机 AR。避免录入 Apple 账号、签名设置、通知和个人信息。建议手机与电脑各录一段 3–5 分钟，操作前准备一张有纹理、光线充足的桌面。

## 准备

1. 运行 `./scripts/dev.sh`，确认电脑能打开 `http://localhost:5173`，手机后端为同一台电脑的 `http://局域网IP:8090`。
2. 安装真机客户端，允许相机与本地网络；测试连接成功。
3. 明确当前数据文件为 `data/issues.json`，不要一端连接测试进程、另一端连接正式进程。演示重启时复用同一个文件。
4. 关闭通知，确认没有录入私人窗口；录像文件放到 `delivery/videos/`，不要提交到源码 Git。

## 手机录像：约 3 分 30 秒

| 时间 | 操作与说明 |
| --- | --- |
| 0:00–0:35 | 打开 FieldNotes，展示后端连接成功（局域网地址可展示，不展示账号）。说明设备是真机、使用 ARKit。 |
| 0:35–1:15 | 缓慢移动，识别水平平面；展示绿色边界。轻点平面放置立方体，再移动手机，展示标记保持世界位置。 |
| 1:15–2:00 | 输入“入口墙面破损”和描述，选择 high；点击 UI 时展示场景中没有新增标记；展示坐标。 |
| 2:00–2:35 | 提交，展示成功提示及 ID；电脑端随后应找到同一标题/ID。 |
| 2:35–3:15 | 再创建一条 low 记录，展示标记颜色区别；或展示断网失败保留草稿、恢复网络安全重试。 |
| 3:15–3:40 | 简述本会话坐标边界，不声称支持历史物理位置恢复。 |

## 保存和核验

- 手机/电脑各 3–5 分钟；文件可命名 `01-iphone-ar.mp4`、`02-web-workflow.mp4`。
- 重播检查文字和提示是否清晰、有无敏感信息、问题 ID 是否对应。
- 填写真实拍摄日期、设备、文件名，并更新 `docs/VERIFICATION.md`。未录制时不可把本脚本当成已交付录像。
