## 提交内容结构

```text
FieldNotes-delivery/
  source/             # Unity/Go/React 源码与文档
  history.bundle      # 完整本地 Git 历史
  videos/
    01-iphone-ar.mp4
    02-web-workflow.mp4
```

`./scripts/package.sh` 生成源码与历史压缩包；视频需要真实录制后放入 delivery/videos，再重新打包。脚本不会自动公开、上传、发邮件或发送 BOSS 消息。
